    Panel draw

    The panel is drawn by lot from all members, balanced by the quotas below, with a published random seed so anyone can rerun the draw (LEXIMIN, Flanigan et al., Nature 2021).

    The draw runs as a pipeline script with the service key; the button is enabled once that script is in place.

    Setting up your own instance

    • Download the kit from GitHub (fork or clone the repository).5 min
    • Create a free Supabase project and run supabase/schema.sql, then your own version of seed.sql.10 min
    • Connect the site: put the project URL and public key in config.js.2 min
    • Put the site online on your own server or web host.5 min
